# 输入、几何校准与积分

## S00：确认输入身份和可用证据

**教程对应：** [T01–T04、T06–T07、D01](tutorial-map.md) 的导入、校准前提、脚本环境部分。来源清单是本技能的工程规则。

先建立文件清单，再读取数据内容。对同名文件比较绝对路径、大小和 SHA-256；用户最新指定的输入位置优先。不要扫描无关目录来猜测样品身份。现成 GPX 可作续作起点，但不能替代输入来源核实。

| 输入 | 必查内容 | 缺失时处理 |
|---|---|---|
| 二维图像及 sidecar metadata | 实际数组尺寸、像素物理尺寸和单位、binning、方向/旋转/翻转、数据类型、已有暗场或背景扣除 | 缺关键几何信息时先核实设备记录；不凭像素数推测像素尺寸 |
| 校准标准的测量图像或有效校准项目 | 标准身份、晶格依据、测量条件、标定时间、与样品配置是否匹配 | 可以教学或建立暂定项目，但不得称“几何已校准” |
| 波长/能量记录 | 单位、单色/双线、来源、可信度，是否存在冲突字段 | 记录冲突，不按文件名或随意取平均解决 |
| 一维粉末谱 | 横轴是 2θ、d、Q 还是 TOF；角度单位；强度和标准差/权重含义；原先的积分处理 | 缺误差时明确权重假设；不得把强度列当标准差 |
| 仪器参数文件/标准谱 | 辐射类型、几何、波长、角度覆盖、探测器设置、仪器峰宽与标准自身展宽 | 不能把软件默认参数称为校准结果 |
| CIF/结构模型 | 化学组成、空间群/setting/原点、晶胞、坐标、占位和 ADP、候选相身份 | 单纯峰位卡片不足以支持含原子结构的 Rietveld；先补结构或限定为峰拟合/索引 |
| 可选空白、暗场、平场、掩膜 | 格式、尺寸、曝光/归一化方式及是否已经应用 | 不重复扣除或套不匹配校正 |
| 已有 GPX/LST/运行记录 | 原图链接、PWDR 来源、phase 关联、最后有效状态、运行版本 | 无法溯源则标记暂定，重新核实后续作 |

原始数据和 CIF 保持只读；另建任务输出目录。所有参数记录数值、单位、来源、是否固定及理由。采集侧名义距离和实际校准距离应分别保存；不把 goniometer radius、图像距离或其他几何量仅因界面相似就自动等同。

## S01：校准二维几何与处理波长

**教程对应：** T01 Step 2–3；需要确定波长时使用 T04；已知波长校准距离参考 T03 Step 1。

1. 导入原始图像，核对物理尺寸。调整灰度/色标使弱环、遮挡和坏点可见；显示截断不等于探测器饱和，不能据色标上限删除数据。
2. 优先采用同配置有效标定。需要重标时导入已知标准，选正确 calibrant/晶格依据；按教程选择环上分布合理的点，检查环识别，精修被数据约束的几何量。
3. 已知可信波长固定，允许所需几何参数调整；距离不是必然固定，也不是必然自由，取决于校准条件。波长未知时必须使用具有足够约束的标准/多距离方法，完整执行 T04，不同时随意放开所有几何量。
4. 放大多个环和不同方位，检查计算环与观测中心的一致性、异常环、遮挡、残差和参数稳定性。标准身份或几何未确认时，不用未知样品的“看起来同心”代替校准。
5. 保存校准项目、图像控制参数和依据；仅对配置兼容的数据复制。探测器距离、binning、方向或装置变化时重新核验，不整套盲目复制。

**通过条件：** 已知量和待定量可区分，标定参数来源明确，环位置无明显系统失配。不能满足时状态为 `needs_input` 或 `provisional`；可以继续可审查的教学，但不能出具最终准确晶格值。

**为什么不默认精修 Lam：** Bragg 关系中波长和晶面间距的整体尺度相关。自由样品晶胞不能为波长提供独立绝对基准。样品 PWDR 的 Lam 与其积分所用波长还必须保持一致；若几何/波长校准改变，检查是否需要重新积分，不能只改最终谱的标签。

## S02：掩膜、积分范围与 PWDR

**教程对应：** T02 Step 2–3；T03 Step 2 Integrating the Calibrated Data。

| 决策 | 依据和操作 | 验证 |
|---|---|---|
| 内界 | 显示积分边界，避开 beamstop、阴影过渡区及无效低角区域，保留可信低角信号 | 放大中心，用光标读取边缘角度；不能因为此前用过某角度就沿用 |
| 外界 | 查看有效探测器覆盖、边缘坏区及所需方位角。选择完整环是便于解释的保守策略；允许部分环时须说明覆盖和均匀性假设 | 检查外界附近不同方位和有效像素；不能把矩形四角或全积分选项当完整环保证 |
| 掩膜 | 对 beamstop 支架、坏点、饱和区、杂散斑点等按实际形态处理 | 保存掩膜并目视复核；斑点可能是样品粗晶，不能自动全当坏点删除 |
| 方位角 | 根据遮挡、织构和环的均匀性选择全方位或分扇区积分 | 必要时比较扇区谱；明显不均匀时记录全环平均的局限 |
| 角度分箱 | 从探测器像素、几何和最窄有效峰估计，再以积分后 FWHM 采样验证 | T02 建议每个 FWHM 超过 6 个点；更细分箱不创造真实分辨率，也不能消除像素相关性 |
| 强度校正 | 偏振、吸收、暗场、平场/背景等按实验依据设置，并追踪已应用的校正 | 防止二维积分与后续强度模型重复校正。低角扣背景后的负值不能未经判断截为零 |

小倾角近似下 `r ≈ L tan(2θ)` 可辅助理解角度边界；真实设置使用 GSAS-II 校准几何。图上颜色可能随版本变化，要以 Inner/Outer 标签和数值识别边界。

先积分一张代表图。检查全谱和局部窄峰、峰位连续性、边缘异常、有效误差/权重及扇区差异。改变几何或掩膜后重新积分，并标识哪份 PWDR 是当前正式数据。

积分区间与 Rietveld `Limits` 不同：前者决定生成的数据，后者选择参与拟合的子集。排除区必须有遮挡、容器或不适用模型等可记录理由，不能单纯为降低 Rwp 删除难拟合峰。

**检查点：** 保存含原始 IMG、Image Controls、Masks 和正式 PWDR 的 GPX。保留来源映射；旧试验谱可以归档，但不能悄悄让多个重复谱同时影响最终精修。
