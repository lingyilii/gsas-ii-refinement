# 分阶段精修与判断方法

**中文** | [English](en/refinement.md)

先读 [输入与校准](input-and-calibration.md)，教程编号见 [tutorial-map.md](tutorial-map.md)。以下是基于教程组织的决策流程；具体放开哪些参数由数据、几何和当前残差决定。

## S03：仪器峰形与可选单峰诊断

**教程对应：** T05 / Intro、Individual peak fitting、Save Instrument Parameters。

优先加载与实验配置匹配的仪器参数。缺少时，可用合适标准建立：背景与峰面积 → 峰位 → 有条件地拟合峰宽 → 仪器峰形表达 → 保存 `.instprm`。每阶段先稳定，再增加变量。覆盖应包括样品使用的角度范围；不能无说明地外推。

独立峰拟合可以帮助看重叠峰和异常峰宽；它不是所有样品进入 Rietveld 前的必经步骤。`Peak List` 中的峰面积、峰位和峰宽也不会自动变成相的原子结构或 Rietveld 模型。

标准自身有尺寸/应变展宽时，要建立有证据的分离方式；没有独立依据，输出只能称“有效峰形参数”。不要先把样品展宽全部吸收到仪器项，再重复精修样品尺寸/应变。

**判断：** 峰位、峰顶、两翼和背景一起检查；单峰 `sigma²`/`gamma` 负值需要处理。不能要求所有 U/V/W 系数均为正：应检查组合得到的高斯方差和实际峰形在整个使用区间内有效。轴向不对称项的采用应符合仪器几何，不能照抄实验室示例的 SH/L。窄角范围内多个峰宽项可能高度相关，应减少自由度。

保存标准项目和峰形依据。GUI 中当前未勾选 Refine 并不表示此前没精修过；实际变化要查阶段日志及前后值。

## S04：导入结构并核对模型

**教程对应：** T06 Step 1–3；T08 Step 2–3；T09 Step I / Read phase files、Map both phases。

1. 在新项目或通过检查的积分项目中导入用户提供的候选 CIF。确认名称与真实组成；不把文件名当结构正确性证明。
2. 核对空间群 setting、原点、晶胞、对称性生成的原子数、元素类型、坐标、占位率和 ADP。混占位须按同一晶体学位点检查总占位和组成。
3. 将每个候选相关联到正式 PWDR，检查 `Use Histogram`。区分“项目中存在这个相”和“它参与这个直方图的拟合”。旧试验 PWDR 不应未经决定参与。
4. 用模型计算初始图谱，比较反射位置和主要峰群。少量峰吻合不能证明物相唯一；候选 CIF 是待检验模型。明显峰位不匹配先查波长、轴单位、校准及模型，不能靠背景掩盖。

**检查点：** 保存初始结构项目，记录所有原子参数初始固定状态、候选相和关联。没有结构原子信息时不要把 Pawley/Le Bail 结果叫 Rietveld；转换方法须另核对相应教程。

## S05：背景、整体尺度与相对贡献

**教程对应：** T06 Step 4–5；T10 Step 2–6；T09 Step I / Prepare for fit: define phase fraction constraint。

先建立能描述非峰区域的简洁背景，检查低角散射、宽弥散峰和容器信号。必要时用固定背景点初始化，再评估最终是否可放开背景；不要用高阶多项式吃掉弱衍射峰。背景阶数由残差决定，没有通用固定值。

选择可辨识的尺度参数化，再做首次整体拟合。可使用“固定整体尺度，拟合各相尺度”，或“整体尺度加带归一约束的相尺度”等等价参数化；不要无约束地同时放开整体尺度和所有相尺度。设置约束后核对实际独立变量列表、约束是否启用。

软件的 phase scale、界面 phase fraction、导出的 Wt. fraction 和原子 `frac` 不可混用。质量分数按 GSAS-II 对当前模型的定义读取，不能将任意相尺度简单归一化冒充质量分数。缺少独立标定时不能由已建模晶相的归一分数推断全样品非晶含量。

**通过条件：** 计算量级合理，背景不吞峰，参与相的尺度没有无依据负值或数值退化。相趋近零时，其晶胞/结构可能不可辨识；先评估该相是否受数据支持，不继续精修它的所有参数。

## S06：修正峰位

**教程对应：** T06 Step 5 后的峰位分析及 Step 6；几何依据回到 T01、T03–T04。

在整体强度稳定后，先释放被数据约束的晶胞参数。再依据实验几何和残差考虑零点或样品位移，避免把波长、晶胞、零点、多个位移项一次全部放开。透射与 Bragg–Brentano 的位移模型不同。

**判断：** 放大多个角度的峰；一致方向偏移与随角度改变的偏移可提示不同原因，但必须通过模型检验确认。差值曲线的正负双叶也可能来自峰位错配。检查晶胞变化量、相关性和化学合理性，不只看 Rwp。

## S07：修正峰宽和峰形

**教程对应：** T06 Step 6–7；T05 的仪器与样品展宽分离。

在峰位稳定后，优先固定已校准仪器峰形，依次测试数据可辨识的样品尺寸和微应变项。先用简洁各向同性模型；只有多个反射显示有规律的 hkl 依赖、且有匹配教程/物理依据时，才考虑各向异性扩展。不同候选模型从同一检查点比较，避免前一次失稳污染下一次。

**判断：** 比较峰顶、峰腰、两侧尾部及重叠区。计算峰高与数据差异不能仅靠改变面积解决。有效尺寸为正、应变物理合理；参数卡在边界、误差极大或与仪器项高度相关时，只报告可支持的有效宽度或界限，不能输出“精确晶粒尺寸”。

## S08：结构参数及有条件的强度修正

**教程对应：** T06 Step 8；T08 的坐标、ADP、同位点等价与占位约束。择优取向等扩展需到 T00 查当前适用教程并记录，不能冒充 T06 必选步骤。

只有峰位、峰形和尺度已稳定才逐组测试原子坐标、ADP。保持对称性限制，检查键长、配位、组成和参数相关性。各向异性 ADP 需要足够信息量和正定性检查；简单数据不必释放。

占位率、元素交换或缺陷浓度仅在散射对比和数据质量支持时精修；先建立位点总占位、组成等适用约束，避免与尺度/ADP 相互补偿。低灵敏度元素或相近散射元素的占位值不能仅凭收敛视为可靠。

若峰位/宽度一致而不同反射强度系统失配，先核对模型、吸收、偏振和二维环均匀性，再评估择优取向。不要默认给所有层状、针状或片状样品套同一轴；不同时开放多个解释相同强度异常的自由度。

## S09：最终联合检查

**教程对应：** T06 / Refinement results；T07 / 多阶段执行与统计；T09 / 顺序拟合结果检查。下面的验收决策是本技能质量规则。

用经过逐步确认的变量集合做最终拟合，保留必要约束。每次保存前后值、独立变量数、数据点数、Rwp、reduced χ²、最大 shift/σ、收敛状态和告警。不同版本字段不可用时写“未知”，不能以零值代替。

| 现象 | 首先排查 | 不能直接得出的结论 |
|---|---|---|
| Rwp 下降但 dropped parameters / singular / false minimum | 重复尺度自由度、零相精修、约束、变量过多、数据支持不足 | “已经收敛，继续加参数” |
| 峰顶有系统差值 | 峰位、宽度、积分采样、重叠、面积；局部放大核实 | “一定只需调强度” |
| 相应位置仍有独立剩余峰 | 漏相、错误结构、容器/杂散、模型缺陷 | “增加背景阶数就完成” |
| 相尺度近零或不确定度很大 | 该相独立反射和可辨识性 | “该相绝对不存在” |
| Uiso 负值、占位异常、峰宽无效 | 数据/模型、参数关联、约束或过度自由 | “低 Rwp 证明结构正确” |
| χ² 很大但轮廓视觉接近 | 高计数、误差模型、相关噪声、系统偏差 | “把权重改小即可变好” |
| 差值整条位于零线下方 | 绘图是否人为平移；数值实际均值 | “整段计算强度都偏高” |

读取最后 `.lst` 与 GPX 的 Covariance，检查异常而不只看截图。出现数值发散、NaN、丢参数或假极小值时退回上一个通过检查的状态、针对证据减少变量或修正模型；不要无限增加循环次数。已点 OK 也要保留失败副本并从有效检查点恢复，不把失败状态继续当起点。

最终状态按 [execution-and-delivery.md](execution-and-delivery.md) 输出。没有通用“Rwp 小于某值就通过”的规则；相同范围、误差模型和输入条件下才可直接比较模型统计量。
